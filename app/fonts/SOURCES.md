# Typeface sources

The recall interface uses **Atkinson Hyperlegible Next**, the exact variable font served by the Braille Institute page the user selected.

- Reference: https://www.brailleinstitute.org/freefont/
- Font: https://www.brailleinstitute.org/fonts/AtkinsonHyperlegibleNextVF-Variable.woff2
- Google Fonts: https://fonts.google.com/specimen/Atkinson+Hyperlegible+Next
- License: `AtkinsonHyperlegibleNext-OFL.txt`, from https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext
- Retrieved: September 19, 2026.

Self-hosted for offline rendering. The frontend loads only Atkinson Hyperlegible Next.
