# Caregiver session bookshelf

Mode: Operate. September 19 bookshelf refinement supersedes the earlier waveform-only composition. This path is retained for existing references.

THESIS: A caregiver browses a quiet shelf of dated calls and opens one observable session receipt. Covers carry call metadata, never biographies, recordings or private memories.

AUTHORITY: Preserve DESIGN.md's self-hosted Atkinson, quiet neutrals and patient experience. The user selected the Framer University 3D bookshelf scroll reference. Original CSS and native scrolling implement that interaction; no third-party code or artwork is copied.

FORM: One full-width horizontal shelf of varying-height light and dark spines aligned along one bottom baseline, with light date lettering, two thin binding rules and a narrow page edge. The nearest neutral cover turns toward the reader and expands to full height, showing topic, date and the existing count waveform. A Call n of n label and previous/next controls indicate position. There is no fixed playhead. The selected receipt and Suggest a conversation remain below; Weekly Note and topic details start collapsed. The two-symbol legend stays visible; topic text filters sit separately above the shelf. A thin Call dates timeline uses elapsed calendar time for its clay current-position marker. It is an indicator, not a slider. The Weekly Note names topics only and shows no patient quotations.

DATA: One cover per fictional dated call. Resting spine height and cover waveform peak height encode the absolute count of unaided calls for that same topic within up to its last eight calls as of that session, always paired with its denominator. Fewer than three calls remains dashed and unmeasured. No transcript, personal words, graph claims, emotional inference or global cognition score enters the session projection. The selected cover expands only for reading; accessible instructions explain that the open cover expands for reading; the visible legend has only two symbols and the count-window definition. Unmeasured spines use a dashed border and light surface.

MOTION: Native horizontal scrolling continuously rotates the nearest cover from −90° toward −8°. Resting spine scale is (80 + 36 × unaided count) / 368; unmeasured scale is 0.37. Measured counts below four use light spines; four and above use dark spines. Openness interpolates scale to 1. Bottom-centered perspective and transform origins preserve a common baseline, while inverse-scaling keeps dates readable. Binding rules at 12% and 88% and the thin page edge are material details, not additional data. Untransformed slots keep snapping stable; cached geometry and one requestAnimationFrame transform update avoid per-frame React renders. Selection persists by session ID. Touch, trackpad, wheel, tapping, keyboard Arrow/Home/End and previous/next controls select the same session. Wheel returns to page scrolling at either boundary. Reduced motion shows spaced flat covers with selected outline, hides spines and backs, uses immediate programmatic scrolling and disables the receipt fade. No looping animation or animation dependency.

RESPONSIVE: Fully open desktop covers measure 232px by 368px with 36px depth and 64px slots; at 600px they become 216px by 330px with 58px slots. Large text raises cover height to 390px. The receipt/contribution area stacks at 800px; the shelf remains horizontal. Navigation controls retain 44px targets. Dark theme and text enlargement inherit the incumbent settings.

QUALITY BAR: The selected cover and receipt agree on date, topic and counts; the receipt adds only a fixed observable support line. Empty and insufficient-history states remain explicit. Hover and focus are visible; reduced-motion geometry is flat. No caregiver design-preview banner or prototype navigation; the sample-data integration note remains.
